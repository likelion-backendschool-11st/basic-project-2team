# 시연 시나리오

가이드 시연 흐름: **회원가입 → 질문 작성 → 답변 → 채택 → 검색** (+ 차별화 기능)
준비: `db/seed.sql` 적용, 백엔드·프론트 실행, 브라우저 일반 창 + 시크릿 창(계정 2개 동시 사용).
데모 계정 비밀번호는 모두 `abc123!@`.

| # | 장면 | 계정 | 확인 포인트 |
| --- | --- | --- | --- |
| 1 | 회원가입 → 로그인 | 새 계정 | 중복확인, 약관 동의, 로그인 후 프로필 설정 |
| 2 | 공고(질문) 작성 | `demohost` | 마크다운 본문 + 미리보기, 게임·유형·인원 선택 |
| 3 | 공고 상세 | 누구나 | 본문이 마크다운으로 렌더링됨(제목·목록·인용·링크) |
| 4 | 질문(댓글) 작성 | `demoasker` | 시드에 이미 질문 1개가 있음 — 새 질문도 작성해 본다 |
| 5 | 답변(답글) 작성 | `demohelper` | 질문에 답글 달기, 답글 접기/펼치기 |
| 6 | **채택** | `demoasker` | 답글의 [채택] 버튼 → 원래 위치 강조 + 맨 위 복사본 + "채택 완료" 배지 |
| 7 | 채택 권한 | `demohost` | 공고 작성자라도 남의 댓글에서는 [채택] 버튼이 없음(API 403 NOT_PARENT_AUTHOR) |
| 8 | 채택 교체·취소 | `demoasker` | 다른 답글로 교체 / 채택 취소 |
| 9 | 검색·페이징 | 누구나 | 게시판 검색창, 카테고리·정렬·태그 필터, 페이지 이동 |
| 10 | 차별화 | 각자 | 파티 신청·승인, 매너 평가(별점·태그), 알림, 관리자 신고 처리 |

## 시연 전 점검
- [ ] 시드 적용됨 (`demohost`/`demoasker`/`demohelper` 로그인 가능)
- [ ] 채택은 아직 아무것도 안 된 상태 (다시 시연하려면 시드의 데모 공고·댓글을 지우고 `db/seed.sql` 재실행)
- [ ] 시크릿 창으로 두 번째 계정 로그인
